Biashara Yangu — Tous les modules

Version 3.3.1 · Ce que fait chaque module, qui l'utilise, les gestes à faire et les pièges à éviter

Comment lire ce document. Chaque module est présenté de la même façon : à quoi ça sert, qui l'utilise, les gestes, puis les pièges. Un module est une brique : l'activité choisie à la création de l'entreprise décide des briques visibles. Rien n'est jamais « cassé » quand un module est masqué — il est simplement hors de propos pour ce commerce.

1. Le socle

1Compte et entreprise

À quoi ça sert : créer l'espace de travail d'un commerce et y rattacher son propriétaire.

Qui l'utilise : le commerçant qui s'inscrit (ou l'agent terrain qui l'accompagne).

Les gestes :

  1. Créer un compte (e-mail + mot de passe), puis se connecter.
  2. Écran de création : saisir le nom du commerce, le téléphone et le type d'activité (boutique, dépôt, hôtel, restaurant, pharmacie, boulangerie, boucherie, salon…).
  3. Choisir le mode : Rapide (nom + prix suffisent pour vendre, essai de 7 jours actif immédiatement) ou Complet (dossier validé par le gestionnaire des comptes puis par la finance).

Les pièges : un même utilisateur peut posséder plusieurs entreprises — inutile de créer un second compte. Le type d'activité se change plus tard sans rien perdre.

2Abonnement, activation et verrouillage

À quoi ça sert : ouvrir le compte au bon moment et le refermer proprement si l'abonnement n'est pas réglé.

Qui l'utilise : le propriétaire (paiement), le gestionnaire des comptes (vérification), la finance plateforme (validation), l'agent terrain (code de validation).

État du compteCe que le commerçant peut faire
Activation en coursConsulter, préparer ses articles. Vendre est refusé (cadenas sur « Nouvelle vente », « Scanner », « Ajouter produit »).
Essai 7 joursTout, sans limite, sans montant réclamé.
ActifTout, jusqu'à la date d'expiration.
Abonnement échu / bloquéConsultation seule ; le verrou est levé dès la validation du paiement.

Les gestes : le propriétaire voit la date d'expiration et le solde restant dans Abonnement ; il paie (espèces, mobile money ou en ligne), la finance valide, le compte se rouvre automatiquement.

Les pièges : le refus est décidé par le serveur, pas par l'écran : un lien direct ne contourne rien. Le code de validation d'un agent terrain n'est valable que pour l'entreprise qu'il accompagne.

3Rôles et permissions

À quoi ça sert : donner à chacun le strict nécessaire.

RôlePortée
PropriétaireTout dans son entreprise.
Caissier (vendeur)Vendre, scanner, encaisser, consulter. Ne modifie jamais un prix.
MagasinierArticles, stock, inventaires, approvisionnements. Pas de caisse ni de finances.
Comptable entrepriseRapports, dépenses, finances (lecture et saisie selon réglage).
Agent terrainAccompagne une boutique, saisit des codes de validation. Ne voit pas les chiffres du commerce.
Gestionnaire des comptes · Finance plateforme · SupportRôles internes de la plateforme, sur des écrans dédiés.
Super administrateurToute la plateforme : entreprises, tarifs, devises, modération, permissions.

Les gestes : Paramètres → Collaborateurs pour inviter ; Permissions (Super Admin) pour ajuster la matrice par rôle.

Les pièges : masquer un écran n'est pas une sécurité — la permission est vérifiée à chaque appel serveur. Ne jamais partager le compte du propriétaire : chaque vente doit être attribuée à une personne.

4Espaces de travail multiples

À quoi ça sert : gérer plusieurs points de vente (boutiques, dépôts) sous le même compte, avec des chiffres séparés.

Les gestes : le propriétaire crée un espace, y choisit un type et une devise ; le sélecteur d'espace bascule d'un point de vente à l'autre. Les ventes, le stock et les rapports restent ceux de l'espace courant.

Les pièges : un collaborateur peut être rattaché à un seul espace ; le total consolidé se lit dans les rapports du compte, pas dans l'accueil d'un espace.

5Devises et taux de change

À quoi ça sert : travailler en CDF ou en USD, avec un taux maîtrisé.

Les gestes : Paramètres → Devise & conversion : choisir la devise de l'espace, saisir le taux « 1 USD = X CDF », vérifier le résultat dans le simulateur. Le Super Admin règle le taux par défaut de la plateforme (Devises & taux).

Les pièges : changer de devise change l'unité d'affichage, pas les montants déjà enregistrés. Un prix saisi en CDF reste un nombre ; c'est l'étiquette qui change. Vérifier le taux avant toute conversion réelle.

2. Le commerce quotidien

6Produits et catalogue

À quoi ça sert : décrire ce que l'on vend : nom, prix, unité, catégorie, seuil d'alerte, code-barres.

Les gestes : Produits → Ajouter (nom + prix suffisent) ; catégories et conditionnements pour ranger ; Importer pour charger un fichier ; les étiquettes QR pour imprimer des codes.

Les pièges : un article sans prix ne peut pas être vendu au comptoir — l'application propose alors « Définir le prix ». Le seuil d'alerte déclenche l'alerte de stock : trop haut, il crie tout le temps ; trop bas, il prévient trop tard.

7Ventes et encaissement

À quoi ça sert : enregistrer une vente, l'encaisser et produire un reçu.

Les gestes : choisir les articles, la quantité, le mode de paiement (espèces, mobile money, crédit), encaisser. Le stock est décrémenté et la vente reçoit un numéro définitif ; l'écran de confirmation rappelle ce qu'il reste en stock pour chaque article vendu.

Les pièges : le prix appliqué est celui du serveur, jamais celui affiché sur le téléphone : une modification faite ailleurs est donc respectée. Une vente ne se « supprime » pas : elle se corrige par un avoir ou un ajustement, pour garder une piste d'audit.

8Scanner et codes-barres

À quoi ça sert : vendre sans taper de nom.

Les gestes : ouvrir le scanner, viser le code. L'application propose alors deux actions :

  • Encaisser maintenant — la vente part directement au paiement (client pressé) ;
  • Ajouter au panier — pour continuer les scans puis payer une fois.

Les codes balance : une balance peut envoyer BAL:503:1250 = article 503, 1,250 kg. Le produit et le poids arrivent ensemble, l'écran de pesée s'ouvre déjà rempli.

Les pièges : le scan est silencieux (plus de son ni de vibration) : c'est le retour visuel qu'il faut regarder. Un code inconnu n'est jamais perdu : il est proposé à la création de l'article.

9Pesée rapide (vente au kilo)

À quoi ça sert : vendre à la balance — viande, riz au détail, légumes — sans calcul mental.

Les gestes :

  1. Choisir le produit pesé (son prix au kilo est rappelé ; sinon « Définir le prix au kilo » ouvre la fiche).
  2. Saisir ou recevoir le poids ; ajuster avec −0,1 / +0,1 / +0,5 kg.
  3. Lire le total calculé, puis Encaisser maintenant ou Ajouter au panier.

Les pièges : le prix au kilo doit être saisi sur la fiche article (une fois) ; l'écran conserve le produit après la vente, ce qui permet d'enchaîner les clients — penser à changer de produit au changement de denrée.

10Caisse et clôture

À quoi ça sert : savoir combien d'argent est réellement dans le tiroir en fin de journée.

Les gestes : encaissements et dépenses de caisse sont enregistrés au fil de la journée ; en fin de service, la clôture compare l'attendu et le compté, et note l'écart.

Les pièges : une sortie d'argent qui n'est pas saisie fausse la clôture. Clôturer chaque jour : un écart de trois jours est indéchiffrable.

11Clients et crédits

À quoi ça sert : suivre qui achète, et surtout qui doit de l'argent.

Les gestes : fiche client (nom, téléphone, zone) ; vente à crédit ; remboursement partiel ou total ; écran des dettes trié par ancienneté.

Les pièges : une vente à crédit n'est pas une rentrée d'argent : elle apparaît en dette, pas en caisse. Le renseignement de la zone sert ensuite aux tournées et au rapport de distribution.

12Stock, approvisionnement, inventaire

À quoi ça sert : savoir ce qui reste, ce qui entre, et corriger les écarts.

Les gestes : Approvisionnement pour une entrée de marchandise ; Ajustement pour une casse ou une erreur ; Inventaire pour compter et aligner.

Les pièges : un ajustement n'est pas une vente : il ne crée pas de chiffre d'affaires (c'est justement ce qui le distingue). Les articles en stock illimité (services, plats) sont exclus des alertes.

13Lots et péremption

À quoi ça sert : vendre d'abord ce qui périme d'abord, et ne jamais vendre un produit périmé.

Les gestes : renseigner lot et date d'expiration sur la fiche article ; régler le délai d'alerte (1 à 365 jours, 30 par défaut) dans Paramètres → Alerte de péremption ; consulter l'écran Expirations, trié par urgence.

Les pièges : le seuil est inclusif (à exactement 30 jours avec un délai de 30, l'alerte est déjà là). Le blocage de vente d'un produit périmé est un réglage distinct (plateforme).

14Dépenses et finance

À quoi ça sert : voir le bénéfice réel, pas seulement les recettes.

Les gestes : saisir une dépense (loyer, transport, salaire) avec sa catégorie ; consulter le tableau des bénéfices ; rattacher les dettes fournisseurs.

Les pièges : une dépense payée depuis la caisse doit être saisie dans la caisse et en finance pour ne rien compter deux fois — se fier à la catégorie, choisie une fois pour toutes.

15Rapports et exports

À quoi ça sert : répondre à « combien j'ai vendu, et qu'est-ce qui marche ? ».

Les gestes : choisir la période et le type (ventes, stock, caisse, dépenses, par activité) ; exporter pour le comptable ; croiser avec le rapport d'agent (partie 3).

Les pièges : les rapports comptent les ventes validées. Un écart entre « ce que je vois » et « ce que je croyais » vient presque toujours d'une vente à crédit ou d'un ajustement de stock.

16Collaborateurs et statistiques par personne

À quoi ça sert : savoir qui a vendu quoi, et fermer l'accès d'un partant.

Les gestes : inviter par e-mail avec un rôle ; l'écran Collaborateurs affiche les ventes et le chiffre d'affaires par personne ; retirer un accès immédiatement.

Les pièges : un collaborateur qui part doit être retiré le jour même : son ancien téléphone garde sinon sa session.

3. La distribution terrain

Le problème résolu. Le patron remplit un carton de marchandises, le confie à un agent, et le soir il ne sait plus exactement ce qui a été vendu, ce qui revient et chez qui sont restés ses casiers. La distribution terrain répond à ces trois questions, avec des chiffres, par agent.

17Tournées de livraison

À quoi ça sert : confier une dotation précise à un agent et suivre son retour.

Qui l'utilise : le propriétaire (préparation, clôture) et l'agent (exécution).

Les gestes :

  1. Tournées → Nouvelle tournée : choisir l'agent, la zone, la date, puis ajouter les produits et les quantités attribuées.
  2. Démarrer : l'agent voit sa tournée sur son téléphone (Ma tournée).
  3. L'agent vend ; chaque vente est plafonnée par la dotation (impossible de vendre ce qui n'a pas été confié).
  4. Clôturer : saisir les quantités retournées. L'application calcule l'écart et le chiffre d'affaires de la tournée.

Le rapport par agent : attribué · vendu · rendu · écart · chiffre d'affaires · consignes ouvertes · bonus accordés · zone, sur la période choisie.

Les pièges : un agent n'a qu'une seule tournée active à la fois. Les prix ne sont jamais fixés par l'agent : ils sont relus en base au moment de la vente, comme partout ailleurs.

18Consignes (récipients laissés chez le client)

À quoi ça sert : savoir combien de casiers, bouteilles ou caisses de l'entreprise dorment chez les clients.

Les gestes : depuis la tournée, enregistrer une consigne (client, libellé du récipient, quantité, zone) ; plus tard, enregistrer la récupération, totale ou partielle.

Les pièges : une consigne reste « chez le client » tant qu'elle n'est pas rendue : c'est un actif de l'entreprise, pas une vente. Un client d'une autre entreprise est refusé. Chaque agent ne voit que ses propres consignes.

19Bonus clients

À quoi ça sert : garder la trace de ce qui a été offert — remise, cadeau, fidélité — pour ne pas le confondre avec une perte.

Les gestes : enregistrer la nature, le montant et une description, rattachés au client et à la tournée du jour. L'écran « Ma tournée » rappelle les bonus du jour local.

Les pièges : un bonus n'est pas une vente : il n'entre pas dans le chiffre d'affaires, il explique une partie du stock manquant.

4. Les modules métiers

Ces modules apparaissent selon le type d'activité choisi. Un hôtel ne voit pas « Pesée », une boutique ne voit pas « Chambres ».

20Hôtel

À quoi ça sert : louer des chambres et suivre les séjours.

Les gestes : Chambres (numéro, type, tarif, état) → Réservations (client, arrivée, départ) → Réception (arrivée, départ, encaissement du séjour).

Les pièges : une chambre occupée non libérée reste indisponible : le départ doit être enregistré, même sans encaissement.

21Restaurant

À quoi ça sert : prendre les commandes à table et les envoyer en cuisine.

Les gestes : Tables (plan de salle) → Commandes (plats, quantités) → Cuisine (écran de préparation) → encaissement.

Les pièges : une table encaissée doit être libérée ; les plats peuvent être vendus en stock illimité (aucune alerte de stock).

22Salle des fêtes

À quoi ça sert : louer une salle par événement, avec acompte et solde.

Les gestes : Salles (capacité, tarif) → Événements (date, client, montant, acompte) ; le solde restant suit l'encaissement.

Les pièges : deux événements ne peuvent pas occuper la même salle le même jour : le conflit est signalé.

23Boulangerie et production

À quoi ça sert : transformer des matières premières en produits finis et connaître le coût de revient.

Les gestes : Matières (farine, sucre…) → Production (recette, quantité produite) ; le stock de matières diminue, celui des produits finis augmente.

Les pièges : une production sans recette ne coûte rien dans les rapports — donc fausse le bénéfice.

24Pharmacie

À quoi ça sert : vendre en respectant les lots et les dates de péremption.

Les gestes : renseigner lot et expiration à la réception ; consulter Expirations ; vendre en priorité les lots les plus proches de la péremption.

Les pièges : un produit périmé peut être bloqué à la vente par le réglage de la plateforme — un message clair l'explique au comptoir.

25Boucherie et pesée

À quoi ça sert : vendre à la découpe, au kilo.

Les gestes : articles vendus au poids (prix au kilo) → écran Pesée (voir module 9) ou code balance scanné.

Les pièges : un article vendu au poids se déclare comme tel : sinon le stock se décrémente en unités et devient faux.

26Variantes (taille, couleur, marque)

À quoi ça sert : vendre un même article en plusieurs déclinaisons, avec un stock propre à chacune.

Les gestes : déclarer les variantes sur la fiche article, choisir la variante au moment de la vente.

Les pièges : le stock se suit par variante : une taille épuisée ne bloque pas les autres.

5. La visibilité : le marketplace

27Vitrine publique et catalogue

À quoi ça sert : être trouvé par des clients qui ne connaissent pas encore la boutique.

Les gestes : la vitrine est visible par défaut ; le propriétaire règle le nom public, la catégorie, la zone, les coordonnées ; chaque article publié apparaît automatiquement dans le catalogue public, avec son prix.

Côté client : recherche sans compte, comparaison des prix, carte des boutiques proches, fiche boutique et fiche produit.

Les pièges : le catalogue public n'expose jamais les données privées (stock exact, clients, chiffres). Dépublier la vitrine la retire immédiatement de la recherche.

28Codes d'attribution et publicités

À quoi ça sert : savoir d'où viennent les clients, et mettre en avant une boutique.

Les gestes : générer un code d'attribution (agent, quartier, campagne) et le diffuser ; acheter une publicité depuis l'écran dédié ; suivre la mesure de visibilité (vues, contacts).

Les pièges : un code mal saisi ne crédite personne : mieux vaut un QR code imprimé qu'un code dicté au téléphone.

6. L'assistant intelligent

29Assistant IA

À quoi ça sert : poser une question en langage courant sur ses propres chiffres : « qu'est-ce qui s'est le mieux vendu cette semaine ? », « qui me doit le plus ? ».

Les gestes : ouvrir l'assistant, écrire la question, lire la réponse chiffrée. Un quota de tokens est consommé à chaque appel ; l'écran Quotas montre le solde et permet d'acheter un pack.

Les pièges : l'assistant a besoin d'internet (contrairement à la caisse). Il lit les données de l'entreprise pour laquelle on est connecté : ne jamais lui demander les chiffres d'un autre commerce.

7. Le paiement en ligne

30SerdiPay — Orange Money, Airtel, M-Pesa, carte

À quoi ça sert : régler un abonnement ou un pack depuis l'application, sans déplacement.

Les gestes : choisir le montant, choisir l'opérateur, confirmer ; l'application attend la confirmation de l'opérateur puis met l'abonnement à jour. Un reçu est conservé dans Factures d'abonnement.

Les pièges : un paiement « en attente » n'est pas un paiement : ne pas relancer avant que le statut change, sous peine de payer deux fois. Si le module n'est pas installé côté serveur, l'écran affiche un message explicite — le reste de l'application continue de fonctionner.

8. Le côté plateforme

31Super administrateur

À quoi ça sert : piloter la plateforme entière.

Les écrans : entreprises (créer avec son propriétaire, consulter la fiche unique), activités et types d'activités, groupes tarifaires (packs et modules inclus), devises et taux, vérification des comptes, activations finance, boutiques, modération, permissions, codes QR, publicités, abonnements.

Les pièges : agir « sur » une entreprise ne donne pas accès à ses données commerciales détaillées : la fiche admin reste une fiche de dossier.

32Agents terrain

À quoi ça sert : faire créer et activer des comptes sur le terrain.

Les gestes : l'agent accompagne le commerçant, saisit un code de validation ; l'entreprise créée lui reste rattachée. Il suit « ses » boutiques.

Les pièges : le code est lié à une entreprise précise ; un code partagé sur les réseaux sociaux est un risque (il ouvre un compte sans contrôle).

33Modération et sécurité

À quoi ça sert : retirer une vitrine trompeuse, suspendre un compte, garder une trace.

Les gestes : signaler ou modérer une boutique depuis l'écran de modération ; le journal d'audit conserve qui a fait quoi et quand.

Les pièges : une suspension coupe les actions sensibles immédiatement, mais ne supprime aucune donnée : la réactivation remet tout en l'état.

9. Le mode rapide

34Interface simplifiée

À quoi ça sert : vendre tout de suite, sans configurer un logiciel de gestion.

Les gestes : à la création, choisir Rapide — l'essai de 7 jours est actif immédiatement. L'accueil ne montre que l'essentiel : vendre vite, mes produits, ajouter un article, pesée, tournées. Les onglets Rapports et Stock sont masqués, les statistiques réduites.

Les pièges : masqué ne veut pas dire perdu : repasser en mode complet (Paramètres) réaffiche tout, avec les mêmes données.

11. Ce que l'application ne fait pas

Pour éviter les malentendus :

  • Elle ne facture pas automatiquement les récipients consignés : elle en garde la trace, la facturation reste une décision commerciale.
  • Elle ne verse pas de commission aux agents : elle calcule et affiche leur performance, le paiement reste manuel.
  • Elle ne remplace pas un comptable : elle fournit des chiffres cohérents et exportables.
  • Elle ne fonctionne pas sans internet pour le marketplace, l'assistant et le paiement en ligne.
  • Elle ne garantit pas un taux de change officiel : le taux est celui que le propriétaire (ou la plateforme) a saisi.
