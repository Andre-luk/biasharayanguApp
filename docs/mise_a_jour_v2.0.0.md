# Mise à jour v2.0.0 — Biashara Yangu

**La grande mise à jour multi-activités** : une seule application pour tous
les métiers — boutique, hôtel, pharmacie, restaurant, salle des fêtes,
boulangerie, boucherie, mode.

## Nouveautés principales

- **Modules métier** (activés selon le type d'activité) : hôtel (chambres,
  réservations, check-in/out, facture séjour), pharmacie (lots & péremption,
  blocage de vente expirée), restaurant (plan de salle, commandes, écran
  cuisine, encaissement caisse), salle des fêtes (calendrier, prestations,
  avances & soldes), boulangerie (matières premières, productions, pertes,
  coût de revient), boucherie (vente au poids, pas de 0,5 kg).
- **Rapports par activité** : occupation des chambres, arrivées & départs,
  commandes restaurant — filtrés selon vos modules actifs.
- **Variantes (mode)** : taille / couleur / marque sur les articles, avec
  recherche par variante.
- **Packs par modules** : votre pack d'abonnement détermine les modules
  disponibles (Essentiel / Avancé / Spécialisé).
- **Nouveau guide d'utilisation complet** : 28 étapes, un bouton « ? » sur
  chaque écran métier.
- **À propos officiel** : éditeur Biashara Tech (Lubumbashi, RDC),
  développeur principal Andre Lukengu, La Perle Corp collaborateur
  (marketing). Conditions d'utilisation et politique de confidentialité à
  jour (droit congolais — Lubumbashi).

## Compatibilité

- Android (APK signé), Windows (installateur + zip), Linux (tar.gz).
- Vos données existantes sont conservées ; les nouveaux écrans apparaissent
  selon votre activité.
