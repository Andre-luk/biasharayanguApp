Créer un compte « agent terrain »

  1. Se connecter avec super.admin@biasharayangu.cd.
  2. Administration → Utilisateurs → « Ajouter un agent terrain ».
  3. Renseigner prénom, nom, adresse e-mail ; utiliser le bouton dé pour générer un mot de passe (8 caractères minimum) et l'afficher.
  4. Valider : le mot de passe est haché par la base, et votre propre session n'est pas remplacée. Notez les identifiants affichés et transmettez-les à l'agent.

2. Créer une boutique — pas à pas

Côté plateforme (agent terrain ou gestionnaire des comptes)

  1. Administration → Entreprises → Nouvelle entreprise : nom de l'entreprise et type d'activité (boutique, hôtel, restaurant, pharmacie, boulangerie, salle des fêtes…). Le dossier part « en attente de vérification ».
  2. Administration → Comptes à vérifier : contrôler le dossier, puis « Vérifier » (ou rejeter avec un motif obligatoire, journalisé).
  3. Administration → Activations & paiements → « Valider le paiement » :
    • saisir le Montant total dû (abonnement) — c'est le montant négocié ; il prime sur le prix du pack tarifaire ;
    • saisir le montant réellement reçu, le mode de paiement et la référence ;
    • valider : paiement total → activation immédiate (30 jours) ; paiement partiel → essai de 7 jours avec solde à régulariser.
  4. Si le compte existe déjà sans montant dû, l'erreur MONTANT_TOTAL_INCONNU disparaît dès que ce montant est saisi : c'est le champ qui manquait.

Côté commerçant (le patron de la boutique)

  1. Se connecter avec son compte (créé avec l'entreprise) : il arrive directement sur le Marketplace public, puis « Mon compte » pour rejoindre son espace.
  2. Articles → Nouvel article : nom, prix de vente, unité de mesure, photo.
  3. Stock → Entrée de stock : la quantité doit être supérieure à zéro pour que l'article soit marqué disponible.
  4. Visibilité (Marketplace) : activer « vitrine visible publiquement » et renseigner la localisation (latitude/longitude). Sans position, la boutique ne peut pas être classée « la plus proche ».
  5. Créer la publication de l'article : il apparaît alors dans le catalogue public, trié par distance.
  6. QR codes : imprimer l'étiquette de la boutique pour la vitrine.
Une boutique visible n'est pas seulement « cochée ». Cinq conditions doivent être réunies : boutique active · vitrine publiée (opt-in du commerçant) · position renseignée · dossier d'activation accepté · entreprise non suspendue. L'écran Administration → Boutiques affiche, pour chaque boutique, la raison exacte de son invisibilité.

3. Chevauchement des rôles

« Chevauchement » = deux personnes différentes peuvent légitimement accomplir la même étape. C'est voulu : cela évite qu'un dossier bloque faute de personnel disponible. Le serveur revérifie toujours le rôle, jamais l'écran.

Les trois zones de chevauchement à connaître

  • Vérification d'un dossier : gestionnaire des comptes et agent terrain et Super Admin. Le premier disponible fait avancer le dossier.
  • Activation + paiement : finance et agent terrain et Super Admin. Sur le terrain, l'agent peut donc clôturer un dossier sans attendre le bureau.
  • Montant total dû : les quatre rôles opérationnels peuvent le fixer — c'est une décision commerciale, pas comptable. Seul le support en est exclu (lecture seule).
Deux garde-fous non chevauchables. (1) Seul le Super Admin touche aux permissions, aux devises et à la configuration de l'assistant IA. (2) Seul le Super Admin peut purger un compte ou une entreprise — et cette purge exige la recopie du nom exact, après une simulation qui affiche le volume de données détruit.
